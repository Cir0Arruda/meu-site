# Oficina Automobilística em 3D

Desenho 3D editável da oficina: gire a câmera, arraste os equipamentos e monte o novo layout.

- `index.html`: página pronta (funciona offline, já traz o three.js embutido).
- `src/oficina.html`: código-fonte da página.
- `build.js`: gera o `index.html` a partir do `src/` (`node build.js`).
- `vendor/`: three.js r147 (licença MIT em `vendor/three-LICENSE`).
